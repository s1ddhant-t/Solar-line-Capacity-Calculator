# Line Capacity Calculator

Premium browser calculator prepared for Siddhant Tripathi.

It includes:

- Stringer capacity from units, cells per string, cells processed per cycle, strings per module and cycle time
- Automatic cells per module = cells per string × strings per module
- Automatic cell module power = cells per module × cell power
- Laminator and automation capacity from cycle time
- Bottleneck-based daily, monthly, quarterly and yearly production
- Quantity output for every production period
- Automatic or manual CTM loss
- W, kW, MW and GW conversion

The calculator runs entirely in the browser and does not require a backend.
