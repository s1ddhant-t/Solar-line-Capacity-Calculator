# Line Capacity Calculator

Interactive browser calculator for:

- Stringer, laminator and automation capacity
- Bottleneck-based daily, monthly and annual output
- Cell-efficiency and cell-watt module power methods
- CTM-adjusted module power
- W, kW, MW and GW conversion

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository.
3. In **Settings → Pages**, choose **GitHub Actions** as the source.
4. The included workflow will publish the calculator automatically.

The calculator runs entirely in the browser and does not require a backend.
