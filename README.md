# Line Capacity Calculator

Simple browser calculator for:

- Stringer, laminator and automation line capacity
- Bottleneck-based daily, monthly and yearly production
- Cell-watt or efficiency-based module power
- CTM-adjusted module power
- W, kW, MW and GW conversion

## Quick setup

1. Enter operating hours, working days, availability and yield.
2. Enter the number of units and rated modules/hour for stringer, laminator and automation.
3. Select the module power method and enter the cell values.
4. Read the bottleneck, production capacity and power output.

The calculator runs entirely in the browser and does not require a backend.
